# 创作约定

本仓库从最终v4开始，用Git提交记录后续修订，不再创建新的prod-00x目录。以下约定是当前叙述与人物边界；用户的新指示优先。当前为23章与不编号的尾声，日记采用非线性顺序。

## 本轮确定的方向

1. VR采用作者确认的超自然经历。程序只是入口，不具有读取心声、身体感受或重建完整人生的工程能力。首次进入发生在江西逃离途中；琴房是随后打开的另一篇日记。
2. 捐献仍由小满选择，她希望救孩子，也强烈希望自己活着回来。补足拒绝、其他选择、评估和生活安排，死亡采用经资料核对的术后肺栓塞作为虚构并发症。
3. 根据作者最后一次调整，收养与赴美均不作结论。不再续写跨年手续，不交代是否成立收养关系；第23章止于身后事和有限相处，尾声保留两人听录音的对话。

4. 本轮按65篇日记组织经历，每篇有明确起止、环境落点和时间证据。顺序来自小满的补记与续写，不按人生年代顺排。读者与绯月共同获知信息，他可以猜错，不能提前引用还没出现的经历。

## 超自然经历的边界

- **入口**：绯月选中最近同步的整份日记，试图找最新住址。第一篇“先出去”却自行展开，将他带进江西逃离现场。开头没有年份，他先误认这是最近失联时的去向；篇末才看见2019及2023年补记。
- **绯月最初的解释**：他没有完整审过AI生成的新增代码，慌乱中把异常归因于AI擅自加入“深度渲染”，把心声理解成AI对日记的解读与生成。吐槽vibe coding、token爆表、自责没审代码和“第一个被自己的AI关起来”，都是他的即时反应，不是小说确认的技术原理。先尝试退出并失败，才寻找解释；短暂惊叹真实度后，立刻回到找人的焦急。
- **顺序**：按副本中她补记、续写的篇目次序推进。写作时间与事件时间不同，逃离、琴房、学费、生产和初识吴小北可以依次出现。第16章看见原稿目录，确认这一顺序来自她的记录；不是AI随机剪辑，也不是实时播放。
- **感知**：只能共享小满当时的感官和心声，不能操纵身体、向她说话、读取他人内心或提前知道结果。过去出现的绯月，是当年的他。
- **真实性**：按超自然真实经历书写，不是AI补全。第16章表明几行文字不含完整感官；第17章已有录音与所经历的现场吻合；第23章住处和练习谱由现实再次印证。不将这些叙事证据写成科学证明。
- **篇间空白**：每篇标出“补记／日记＋标题”，场景结束后声音、触感或画面退回字页，随后有不能操作的空白。这里仍没有自己的身体，不是每篇结束都能回现实。下一篇先用衣着、地点、物件、单据或日记上的标记重新定位。
- **最后结束**：第1章给出整份副本的最后保存时间；第16章看见补记原稿并猜测能否读到末尾；第21章最后一篇对上同一日期及20:41。这次不再出现下一篇，随后在现实中醒来。不能把普通篇末与整个副本结束混为一谈。
- **外部**：绯月半小时不回复，个子小联系持有备用钥匙的同事。同事在七点多摘掉头显、关电脑、叫急救，绯月仍无反应。傍晚在医院醒来，回到自己身体后才了解救援经过。不能重新改成朋友整日无人过问，或普通软件锁死退出。
- **不可解释之处**：为什么偏偏发生在这份日记、意识怎样进入过去，保持神秘。不要补造神经扫描、AI模型或“读完才能安全退出”的程序功能。

## 寻找线索与误判

第1章先把逃跑误当成近期去向，篇末年份将这一猜测推翻。第2—3章退到高二和学费；第4章突然进入2019年生产，绯月才知道有孩子、孩子父亲另有其人。第5—7章先见吴小北的照顾，再补成都的窘迫和江西的控制。第8章先亲见父母来接，再遭遇劝回；第9—11章补出她第一次为何离家。第12章回到河边和准备逃离的几天，与第1章接上。

后半部通过新的工作地点、日期、熟悉的群公告、租房消息和医院信息逐步靠近现在。多数近期日记相对顺序接近实际时间，但第20章仍明确补记了更早的声乐咨询。

绯月的推测须有当时可见的依据。对小满的误解可以修正；不能把修正理解写成替施暴行为开脱。发现一个日期，只能说明那篇记录的时间，不能拿它推算现实中已过去多久。

第一篇的危险主要来自受限的视角、身后的动静、小满怕被认出及身体虚弱。没有新增吴小北追车或亲眼确认有人追捕的事实。绯月由想退出程序转为催她快走，因而有实际的恐惧去跟随她；吐槽放在暂时缓过一口气时。

完整篇目及时间见[日记场景与时间](<日记场景与时间.md>)。

## 人物与声音

- 周航有真实的共同生活场面。提前出现借用手机后退出页面、回避钱的解释、用礼物开配合要求的玩笑；不在伏笔处宣布他将施暴。
- 马成的现实退缩、吴小北的控制和强迫、周航的债务及暴力、郑哥的情感缺席保持不同。郑哥不索债、不施暴；小满后来把等他的空档重新用于工作，也不再为一句问候延长夜晚。
- 压缩绯月重复陈述不公平的评论，保留他对马成的轻蔑、对孩子天然亲密的误判、对周航的轻信、对郑哥的道德冲突和嫉妒、一命服上的优越感。
- 心声用「」，对白用“”。减少同一种输入、删除、停住的节奏；部分换为不点消息、翻回前文、语音取消和具体行动。
- 原有唱歌、游戏、番茄炒蛋等相处保留。两人仍是普通朋友，不补告白或共同未来。

## 第21—23章

小满问过等待逝者捐献肝源与其他自愿亲属评估，也问自己只出钱是否可以。她暂停评估，回去上课、做饭，实际说出暂不准备捐献；之后在数次接触和独立谈话中重新决定继续。孩子仍亲奶奶，对她生疏，有自己的画、椅子和要求；不通过突然喊妈妈、求她救命或隐藏母爱推动决定。

风险告知、身体评估和伦理审查均经过一段时间。医生不许诺安全或一周复工。小满安排上海生活与恢复后的课，不以捐献交换回吴家，也要求吴小北继续承担孩子的事。

小满术后第二天发生肺栓塞，治疗中短暂相对稳定，能有费力的表达，随后恶化。绯月实际见到她时已经去世；“让孩子活下去”“想活、回去上课”仍只能由个子小在此后转述。不得把供者死亡写成常见结果，或把事故归因于她从前挨饿、低血糖或心理创伤。

第23章，朋友办理告别、整理她自己选择的住处，绯月承担治疗安排，但不因此获得孩子的法律身份。孩子要奶奶、不愿让出奶奶的椅子，后来才愿意让绯月一起画画。尾声不标地点、不标年月、不加收养结论，末句仍为“我再听听。”

小满与孩子不亲；没有结婚登记；结尾不扩写其父母。原尾声逐字保留。人物基础见[人物](人物.md)。此前“医学只概述”和“必须收养赴美”的限制已被后续要求替换。
