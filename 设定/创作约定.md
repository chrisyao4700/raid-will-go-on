# 创作约定

本仓库从最终v4开始，用Git提交记录后续修订，不再创建新的prod-00x目录。以下约定是当前叙述与人物边界；用户的新指示优先。当前为23章与不编号的尾声，日记采用非线性顺序。

## 本轮确定的方向

1. VR采用作者确认的超自然经历。程序只是入口，不具有读取心声、身体感受或重建完整人生的工程能力。首次进入发生在江西逃离途中；其后切到琴房，正文不通过日记标签宣布场景。
2. 捐献仍由小满选择，她希望救孩子，也强烈希望自己活着回来。补足拒绝、其他选择、评估和生活安排，死亡采用经资料核对的术后肺栓塞作为虚构并发症。
3. 根据作者此次调整，第23章明确吴小北同意让乐乐跟绯月生活、由绯月抚养，并愿配合后续安排；吴母同意交托。正式收养、监护及赴美手续不作完成结论，不续写跨年办手续；尾声保留两人听录音的对话。

4. 内部按65段日记经历组织，正文保留场景断点，但不显示“补记／日记”标签、分场标题或说明性时间地点栏。先呈现环境、物件、动作及对白，必要时才让绯月推测。年份可从挂历、手机、票据等实物出现；线索的可信程度也要符合实物本身，旧挂历不能自动证明事件当天的年份。

5. 第4章在江西村里的吴家生产。绯月的反应首先是对生产现场的惊恐，随后是“小满竟然生过孩子”的巨大震惊。小满对新生儿有真实的母爱和保护欲，同时恨被限制自由、急切盼望离开；吴小北和吴母真心为孩子出生而兴奋，却不兑现放她走的承诺。

6. 吴小北与吴母都有真实困境，也都对伤害小满负责。成都的恋爱、贫穷与自卑、未明病因的旧肝病、深夜争吵、临产承诺和晚年依靠的恐惧串成暗线。2026年吴小北病情严重，不能捐肝；最终同意让孩子离开，不能因此取消早年的欺骗和强迫。

7. 绯月夜里在自己家中进入VR，被困一夜，清晨由AI助手雪梨营救成功，仍在自家椅子上醒来。删除同事救援、备用钥匙、急救及绯月住院留观的支线。雪梨在分娩时首次感受到异常强烈的情绪反馈，随后不断干扰渲染寻找他；绯月认出提示，利用转场残留的数字、日期协助定位，最后凭完整保存日期与20:41脱困。

8. 周航家境殷实，知道小满有孩子后仍真心谈婚。母亲在谈婚事时得知过去，以测试她是否看重钱财为由推动拆散；周航接受试探，自行偷用花呗，仍对借贷和施暴负责。暗线通过母亲来电、推迟见面、母子措辞及八千元抵扣呈现；不增加尾声后的信或忏悔番外。

## 超自然经历的边界

- **入口**：绯月选中最近同步的整份日记，试图找最新住址，意识却进入逃离现场。小满刚买的车票上，乘车日期露出2019，绯月由此发现眼前并非最近的事；此时还不知道这些经历何时补写、保存，不能由日记末行直接宣布年份和地点。
- **绯月最初的解释**：他没有完整审过AI生成的新增代码，慌乱中把异常归因于AI擅自加入“深度渲染”，把心声理解成AI对日记的解读与生成。吐槽vibe coding、token爆表、自责没审代码和“第一个被自己的AI关起来”，都是他的即时反应，不是小说确认的技术原理。先尝试退出并失败，才寻找解释；短暂惊叹真实度后，立刻回到找人的焦急。
- **顺序**：经历对应她留下的文字片段，读取次序不等于事件发生次序，也不能由场景中的电脑年月推定那段文字在副本中的位置。第14章通过实际打开的文字，让绯月猜到自己可能跟着记录走；不要把这个猜测写成已证实的排序算法，更不能暗示程序为了悬念编造事件。
- **感知**：只能共享小满当时的感官和心声，不能操纵身体、向她说话、读取他人内心或提前知道结果。过去出现的绯月，是当年的他。新增的有限能力只作用于渲染异常：集中注意力记住的少量视觉内容，可能在转场或画面失稳时留下残影，成为雪梨能接收的反馈；不能借此改写小满的行动或过去。
- **真实性**：按超自然真实经历书写，不是AI补全。第14章表明几行文字不含完整感官；第13章已有录音与所经历的现场吻合；第23章住处和练习谱由现实再次印证。不将这些叙事证据写成科学证明。
- **篇间空白**：正文以分隔线和适量感官中断区分经历。空白里仍没有能自由操作的身体，也不是每次结束都返回现实。省去“页首写着哪里”“下一篇叫某某”的报幕；新的地点先通过视野和声音逐渐显现。
- **最后结束**：第1章保留副本最后保存日期与20:41。第14章发现事件年份与补写、保存时间不同，改用两类时间交叉传信，并猜测实际保存的那一刻能提供精确位置。第21章通过手机显示的日期及20:41与入口信息对上，绯月反复补传缺位，雪梨回显完整时间后完成定位和营救。不能写成读完日记自动退出，或不许提前离开的程序规则。小满实际写日记、看开团提醒属于场景行动，不能改成章前定位字幕。
- **外部**：雪梨与浏览程序都在家中的设备上持续运行，不增加云端营救或第三人到家。绯月醒来仍戴头显，自己将其摘下；此时才知道现实只过了一夜，并从雪梨的简短说明及记录核对救援经过。随后由自己联系个子小、报告医院、取证件并乘当日航班回国。朋友仍在并行寻找小满，不因夜里未得到绯月回复而展开救援。
- **不可解释之处**：为什么偏偏发生在这份日记、意识怎样进入过去、情绪及注意力如何影响异常文件，保持神秘。普通退出已失败，程序报告会话结束却仍生成异常渲染文件；这不是软件原有的体验功能。雪梨能定位并干扰入口，不能读取完整心声或重建小满的人生。不要补造神经扫描、读心模型或“读完才能安全退出”的功能。

## 雪梨营救与传信边界

- 第1章提前介绍长期使用的AI助手雪梨。窗口边缘“短亮两下，再长亮一下”是绯月设置的任务处理提示，必须先建立熟悉感。第2—3章依次尝试寻找现实声音、利用转场找身体和倒想场景，自救均失败。
- 第4章情绪失控成为雪梨发现被困的起点。正文只写绯月见到的闪白、缺失及数字残留；雪梨何时发现他，在第22章醒来后确认，不另开外部视角。第5—7章逐步重复异常，第8章认出熟悉节奏，第9章用停止想象后仍出现的整齐数字回显，确认外面收到了回应。
- 他不能自由打字、说话或移动视线。残影短暂、易散，数字通常比复杂文字容易留住，传完整日期也可能丢位。收得到什么，就只回显什么；不能把固定的任务提示自动当成全部内容已收齐。第11章开始分段传日期，第14章改变定位方法，第18章学会只补缺位。
- 事件日期不能当作文件日期。旧资料、挂历、没有年份的预约页面都有误判可能。第14章以2023年补写2019年生产经历说明两者区别，之后以可见日期、补写关系和经过片段的先后缩小范围。绯月在当时只能推测雪梨的做法，第22章才由她确认。
- 第20章主动试传小区、楼幢和门牌，只有502得到回显，无法凭此确认地址；第21章也试过医院名称而失败。不能人为规定通道“只能传日期”，也不能让绯月获得可用通道后不尝试直接帮助小满。
- 异常总体加重，从少量失色、闪白，发展到局部停帧、回显、声音与画面错开和大片缺失；中间允许失去回应、短暂恢复完整，使他从害怕故障转为害怕雪梨失联。分娩、自伤、河边转念、施暴及唱歌等场面保持主体完整，不让每段都以故障收尾。
- 第21章最后日期与20:41只在绯月真正走到对应片段、成功补传后成为有效定位，不是提前背出备份时间就能跳到末尾的口令。最终营救由双方此前的排查和回应累积促成。

现实时间以绯月醒来对应的中国日期为D日：最后保存是D−3日20:41，手术是D−2日，D日早上发生术后第二天的并发症。绯月在美国西海岸前一夜进入，对应中国D日下午；当地次日清晨醒来，对应中国D日夜间，现实仅过一夜。他搭当地当日中午的航班，约十四小时后在中国D＋1日抵达。正文不增加日期报幕，具体推演见[日记场景与时间](日记场景与时间.md)。

## 寻找线索与误判

第1章先怀疑逃跑与近期失联有关，看到刚买的车票上印着2019年，才发现进入了过去。第2—3章退到高二和学费：谱夹上的“距高考445天”、校服及2016年学校资料自然交代阶段，琴房不标“高二”。绯月只知道马成曾与她相处、帮助过学费，不能预设共同出走。第4章突然进入2019年村中生产，绯月才知道小满生过孩子，并在现场听到吴小北和乐乐的名字。第5—7章先见吴小北的照顾，再补成都的窘迫和江西的控制。第6章车票只给2017年的线索，成都来自她求职电话里的原话；不能由票数推论私奔，也不提前补出她离家的原因。第7章由村医上门验孕，本子上当次记录的日期露出2018；小满仍主动借电话求助，吴小北口头应允后继续阻拦，没有去医院的行程。第8章只看到她借电话求助、等父母，第9—11章补出她第一次为何离家、是否邀请马成同行。第12章回到河边和逃离准备，与第1章接上，再让父母真正来接、送她回家休息。父母要求回吴家的那顿饭，到第16章才看见。

后半部通过工作环境变化、手机或票据日期、熟悉的群公告、租房聊天和医院信息逐步靠近现在。第20章由聊天记录的时间显示声乐咨询早于一命服，不再加“补记”标签。

绯月的推测须有当时可见的依据。能从环境自然看明白的，不再让他重复解释；也不要每一段都追加一番猜测。对小满的误解可以修正；不能把修正理解写成替施暴行为开脱。一个日期只能支持其具体来源对应的时间判断：事件、票据、记录或保存各不相同，不能拿它推算现实中已过去多久。

第一篇的危险主要来自受限的视角、身后的动静、小满怕被认出及身体虚弱。没有新增吴小北追车或亲眼确认有人追捕的事实。绯月由想退出程序转为催她快走，因而有实际的恐惧去跟随她；吐槽放在暂时缓过一口气时。

## 第三部的阅读顺序与因果

第13—20章依次为《那明天见》《郑哥》《新房》《上线》《那是送我的》《只唱一遍》《一命服》《她想去上海》。第二部以父母接回、暂时安顿收束；第三部先见成熟主播，再补她怎样走到这里。

| 阅读位置 | 已呈现的事实 | 暂未获得的因果 |
|---|---|---|
| 13《那明天见》 | 2025年末，绯月第一次进团，设备与指挥已经成熟 | 回家后为什么又出来、怎样谋生；绯月可能先把安顿归功于家里 |
| 14《郑哥》 | 2023年资助电脑、真实亲密、逐渐退出；最后切到2021年的手伤 | 郑哥如何进入她生活、她何时决定直播、手伤如何发生 |
| 15《新房》 | 周航的相处、共同生活、双方送礼与婚姻期待；母亲得知小满有孩子后，见面推迟，周航问起没钱以后的生活并借用手机；她的手仍好 | 偷用花呗与试探尚未明说；不因阅读顺序就认定周航出现在郑哥之后 |
| 16《上线》 | 回家后被劝回吴家，自己找住处，阿禾介绍陪玩；伤愈还款时翻看周母把恋爱开销净额八千抵扣欠款的清单与旧消息；主动试直播，郑哥首次到直播间 | 八千如何被扣下已明确，花呗未经同意被使用的经过、周航试探及手伤原因仍待看见 |
| 17《那是送我的》 | 周航承认未经允许使用花呗，说漏试探意图；“真遇上点事”与周母语音呼应，搬离时施暴 | 与此前抵扣清单、检查单及分期还款完成对应；母亲的全盘意图不由旁白宣布 |
| 18—20 | 朋友相处、一命服分歧与声乐、上海住址 | 逐步逼近眼下失联，继续第四部 |

绯月的主要误解是把他人的资助当作她职业选择的起点，以及看到周母也减去小满送键鼠的两千，短暂把账目算得仔细当作分摊有理。真实因果是：她先谋生、先决定试直播，后来才遇郑哥；花呗由周航未经她同意使用，八千是母亲将赠与追算为欠款的抵扣额。第16章已看见清单与小满反对，不能到第17章重新猜八千从何而来。

公平性要求：手伤检查单明确露出2021，早于2023年的郑州电脑；不能据剪接就指认郑哥施暴。还款场景明确三万八的欠款、周母仅还三万、八千按恋爱开销抵扣，以及小满曾反对赠礼抵债并追问余额；清单代表母亲的算法，不是旁白确认小满应负担的债务。新房里完好的手、深浅杯子、借来的电脑、初次来访的对话均作为可辨认的线索。

郑哥初次听她讲的是甘肃、江西、父母接回又劝回的经历；没有把这一次对话写成完整讲述周航借贷和施暴。不能在第16章声称这些细节已经听全，再到第17章假装第一次知道。此处也不以他给过钱否认两人真实相处。

第三部实际事件先后仍是：父母接回后劝回吴家 → 她再次离家做陪玩 → 与周航相处、欠款及搬离受伤 → 恢复与还款 → 自己决定试直播 → 认识郑哥并得到支持、郑州安顿 → 郑哥淡出 → 与绯月相识 → 唱歌、一命服和上海。早于一命服的声乐咨询仍通过聊天日期表现。

## 人物与声音

- 周航有真实的共同生活场面。双方送礼和谈婚在先，母亲得知过去后见面推迟；随后问起没钱以后的生活、借用手机后退出页面。用礼物开配合要求的玩笑仍保留，不在伏笔处宣布他将施暴。
- 马成的现实退缩、吴小北的控制和强迫、周航的债务及暴力、郑哥的情感缺席保持不同。郑哥不索债、不施暴；小满后来把等他的空档重新用于工作，也不再为一句问候延长夜晚。
- 压缩绯月重复陈述不公平的评论，保留他对马成的轻蔑、对周航的轻信、对郑哥的道德冲突和嫉妒、一命服上的优越感。分娩是一次重大认知冲击，不能让他迅速冷静下来评判小满是否像一个合格母亲。
- 心声用「」，对白用“”。减少同一种输入、删除、停住的节奏；部分换为不点消息、翻回前文、语音取消和具体行动。
- 原有唱歌、游戏、番茄炒蛋等相处保留。两人仍是普通朋友，不补告白或共同未来。

## 周航暗线与知情范围

- 作者层面的因果：母亲得知小满有孩子后不愿儿子与她结婚，借测试是否拜金促使周航怀疑她。周航想证明两人能过日子，接受试探；他不清楚母亲想拆散的完整意图，却知道自己在试探，偷用花呗及搬离时的施暴均是他的选择。
- 正文不另开母子密谋视角。第15章小满听到周航说“她一开始就跟我说了”“孩子跟那边过”，知道母亲得知过去；后续见面迟迟未定，周航询问假如没钱是否仍一起生活。小满当时可以理解为装修后手头紧，不预先知道测试。
- 第15章章内顺序为D30、D31、D32、D33、D35、D36、D37、D34：先有共同生活、生日礼物与键鼠回赠，再有谈婚和母亲来电，最后洗照片时借用手机。D34接过章末雪梨传信，仍只确认预约页面的月日，不套用检查单的年份。

## 第21—23章

小满问过等待逝者捐献肝源与其他自愿亲属评估，也问自己只出钱是否可以。她暂停评估，回去上课、做饭，实际说出暂不准备捐献；之后在数次接触和独立谈话中重新决定继续。孩子仍亲奶奶，对她生疏，有自己的画、椅子和要求。出生时的母爱与多年分离后的生疏可以并存；不能让孩子突然亲近她、求她救命，也不能把母爱写成必须捐献的义务。
