# 创作约定

本仓库从最终v4开始，用Git提交记录后续修订，不再创建新的prod-00x目录。以下约定是当前叙述与人物边界；用户的新指示优先。当前为23章与不编号的尾声，日记采用非线性顺序。

## 本轮确定的方向

1. VR采用作者确认的超自然经历。程序只是入口，不具有读取心声、身体感受或重建完整人生的工程能力。首次进入发生在江西逃离途中；其后切到琴房，正文不通过日记标签宣布场景。
2. 捐献仍由小满选择，她希望救孩子，也强烈希望自己活着回来。补足拒绝、其他选择、评估和生活安排，死亡采用经资料核对的术后肺栓塞作为虚构并发症。
3. 根据作者最后一次调整，收养与赴美均不作结论。不再续写跨年手续，不交代是否成立收养关系；第23章止于身后事和有限相处，尾声保留两人听录音的对话。

4. 内部按65段日记经历组织，正文保留场景断点，但不显示“补记／日记”标签、分场标题或说明性时间地点栏。先呈现环境、物件、动作及对白，必要时才让绯月推测。年份可从挂历、手机、票据等实物出现；线索的可信程度也要符合实物本身，旧挂历不能自动证明事件当天的年份。

5. 第4章在江西村里的吴家生产。绯月的反应首先是对生产现场的惊恐，随后是“小满竟然生过孩子”的巨大震惊。小满对新生儿有真实的母爱和保护欲，同时恨被限制自由、急切盼望离开；吴小北和吴母真心为孩子出生而兴奋，却不兑现放她走的承诺。

## 超自然经历的边界

- **入口**：绯月选中最近同步的整份日记，试图找最新住址，意识却进入逃离现场。车门旁的旧挂历露出2019，他怀疑可能是没换的挂历，也可能进入了过去；不能由日记末行直接宣布年份和地点。
- **绯月最初的解释**：他没有完整审过AI生成的新增代码，慌乱中把异常归因于AI擅自加入“深度渲染”，把心声理解成AI对日记的解读与生成。吐槽vibe coding、token爆表、自责没审代码和“第一个被自己的AI关起来”，都是他的即时反应，不是小说确认的技术原理。先尝试退出并失败，才寻找解释；短暂惊叹真实度后，立刻回到找人的焦急。
- **顺序**：经历对应她留下的文字片段，读取次序不等于事件发生次序，也不能由场景中的电脑年月推定那段文字在副本中的位置。第14章通过实际打开的文字，让绯月猜到自己可能跟着记录走；不要把这个猜测写成已证实的排序算法，更不能暗示程序为了悬念编造事件。
- **感知**：只能共享小满当时的感官和心声，不能操纵身体、向她说话、读取他人内心或提前知道结果。过去出现的绯月，是当年的他。
- **真实性**：按超自然真实经历书写，不是AI补全。第14章表明几行文字不含完整感官；第13章已有录音与所经历的现场吻合；第23章住处和练习谱由现实再次印证。不将这些叙事证据写成科学证明。
- **篇间空白**：正文以分隔线和适量感官中断区分经历。空白里仍没有能自由操作的身体，也不是每次结束都返回现实。省去“页首写着哪里”“下一篇叫某某”的报幕；新的地点先通过视野和声音逐渐显现。
- **最后结束**：第1章保留副本最后保存时间。第14章由实际日记文字和电脑年月形成走到末尾的猜测；第21章通过手机显示的日期及20:41与入口信息对上，随后返回现实。小满实际写日记、看开团提醒属于场景行动，可以保留；不能把它们当作章前定位字幕。
- **外部**：绯月半小时不回复，个子小联系持有备用钥匙的同事。同事在七点多摘掉头显、关电脑、叫急救，绯月仍无反应。傍晚在医院醒来，回到自己身体后才了解救援经过。不能重新改成朋友整日无人过问，或普通软件锁死退出。
- **不可解释之处**：为什么偏偏发生在这份日记、意识怎样进入过去，保持神秘。不要补造神经扫描、AI模型或“读完才能安全退出”的程序功能。

## 寻找线索与误判

第1章先怀疑逃跑与近期失联有关，看到车上的旧挂历后才对时间产生疑问。第2—3章退到高二和学费，绯月只知道马成曾与她相处、帮助过学费，不能预设共同出走。第4章突然进入2019年村中生产，绯月才知道小满生过孩子，并在现场听到吴小北和乐乐的名字。第5—7章先见吴小北的照顾，再补成都的窘迫和江西的控制。第6章车票只给2017年的线索，成都来自她求职电话里的原话；不能由票数推论私奔，也不提前补出她离家的原因。第8章只看到她借电话求助、等父母，第9—11章补出她第一次为何离家、是否邀请马成同行。第12章回到河边和逃离准备，与第1章接上，再让父母真正来接、送她回家休息。父母要求回吴家的那顿饭，到第16章才看见。

后半部通过工作环境变化、手机或票据日期、熟悉的群公告、租房聊天和医院信息逐步靠近现在。第20章由聊天记录的时间显示声乐咨询早于一命服，不再加“补记”标签。

绯月的推测须有当时可见的依据。能从环境自然看明白的，不再让他重复解释；也不要每一段都追加一番猜测。对小满的误解可以修正；不能把修正理解写成替施暴行为开脱。发现一个日期，只能说明那篇记录的时间，不能拿它推算现实中已过去多久。

第一篇的危险主要来自受限的视角、身后的动静、小满怕被认出及身体虚弱。没有新增吴小北追车或亲眼确认有人追捕的事实。绯月由想退出程序转为催她快走，因而有实际的恐惧去跟随她；吐槽放在暂时缓过一口气时。

内部场景代号、作者时间轴与可见线索见[日记场景与时间](<日记场景与时间.md>)。表中代号与日期供编辑核对，不是正文标签，也不代表绯月已知这些信息。

## 第三部的阅读顺序与因果

第13—20章依次为《那明天见》《郑哥》《新房》《上线》《那是送我的》《只唱一遍》《一命服》《她想去上海》。第二部以父母接回、暂时安顿收束；第三部先见成熟主播，再补她怎样走到这里。

| 阅读位置 | 已呈现的事实 | 暂未获得的因果 |
|---|---|---|
| 13《那明天见》 | 2025年末，绯月第一次进团，设备与指挥已经成熟 | 回家后为什么又出来、怎样谋生；绯月可能先把安顿归功于家里 |
| 14《郑哥》 | 2023年资助电脑、真实亲密、逐渐退出；最后切到2021年的手伤 | 郑哥如何进入她生活、她何时决定直播、手伤如何发生 |
| 15《新房》 | 周航的相处、共同生活、礼物与婚姻期待；她的手仍好 | 欠款与伤害的前因仍未展开；不因阅读顺序就认定周航出现在郑哥之后 |
| 16《上线》 | 回家后被劝回吴家，自己找住处，阿禾介绍陪玩，伤愈后还款，主动试直播，郑哥首次到直播间 | 剩下八千的实际来源、手伤原因仍待看见 |
| 17《那是送我的》 | 周航承认未经允许使用花呗，搬离时施暴 | 与此前检查单、分期还款完成对应 |
| 18—20 | 朋友相处、一命服分歧与声乐、上海住址 | 逐步逼近眼下失联，继续第四部 |

绯月的主要误解是把他人的资助当作她职业选择的起点，以及将欠在她名下的余额猜成她自己的开销。真实因果是：她先谋生、先决定试直播，后来才遇郑哥；花呗由周航未经她同意使用。

公平性要求：手伤检查单明确露出2021，早于2023年的郑州电脑；不能据剪接就指认郑哥施暴。还款场景保留“周航母亲替儿子还三万”的事实，误判只限余下八千是否为共同开销，不能删去已知事实诱导读者。新房里完好的手、深浅杯子、借来的电脑、初次来访的对话均作为可辨认的线索。

郑哥初次听她讲的是甘肃、江西、父母接回又劝回的经历；没有把这一次对话写成完整讲述周航借贷和施暴。不能在第16章声称这些细节已经听全，再到第17章假装第一次知道。此处也不以他给过钱否认两人真实相处。

第三部实际事件先后仍是：父母接回后劝回吴家 → 她再次离家做陪玩 → 与周航相处、欠款及搬离受伤 → 恢复与还款 → 自己决定试直播 → 认识郑哥并得到支持、郑州安顿 → 郑哥淡出 → 与绯月相识 → 唱歌、一命服和上海。早于一命服的声乐咨询仍通过聊天日期表现。

## 人物与声音

- 周航有真实的共同生活场面。提前出现借用手机后退出页面、回避钱的解释、用礼物开配合要求的玩笑；不在伏笔处宣布他将施暴。
- 马成的现实退缩、吴小北的控制和强迫、周航的债务及暴力、郑哥的情感缺席保持不同。郑哥不索债、不施暴；小满后来把等他的空档重新用于工作，也不再为一句问候延长夜晚。
- 压缩绯月重复陈述不公平的评论，保留他对马成的轻蔑、对周航的轻信、对郑哥的道德冲突和嫉妒、一命服上的优越感。分娩是一次重大认知冲击，不能让他迅速冷静下来评判小满是否像一个合格母亲。
- 心声用「」，对白用“”。减少同一种输入、删除、停住的节奏；部分换为不点消息、翻回前文、语音取消和具体行动。
- 原有唱歌、游戏、番茄炒蛋等相处保留。两人仍是普通朋友，不补告白或共同未来。

## 第21—23章

小满问过等待逝者捐献肝源与其他自愿亲属评估，也问自己只出钱是否可以。她暂停评估，回去上课、做饭，实际说出暂不准备捐献；之后在数次接触和独立谈话中重新决定继续。孩子仍亲奶奶，对她生疏，有自己的画、椅子和要求。出生时的母爱与多年分离后的生疏可以并存；不能让孩子突然亲近她、求她救命，也不能把母爱写成必须捐献的义务。

风险告知、身体评估和伦理审查均经过一段时间。医生不许诺安全或一周复工。小满安排上海生活与恢复后的课，不以捐献交换回吴家，也要求吴小北继续承担孩子的事。

小满术后第二天发生肺栓塞，治疗中短暂相对稳定，能有费力的表达，随后恶化。绯月实际见到她时已经去世；“让孩子活下去”“想活、回去上课”仍只能由个子小在此后转述。不得把供者死亡写成常见结果，或把事故归因于她从前挨饿、低血糖或心理创伤。

第23章，朋友办理告别、整理她自己选择的住处，绯月承担治疗安排，但不因此获得孩子的法律身份。孩子要奶奶、不愿让出奶奶的椅子，后来才愿意让绯月一起画画。尾声不标地点、不标年月、不加收养结论，末句仍为“我再听听。”

## 保持不变的主要事实

陈奈1999年生、甘肃、173厘米；绯月1990年生、南京、中国护照与美国绿卡、AI工程师。游戏团员使用：哈哈姐、万哥、地哥、个子小；郑哥与地哥不是同一人。

班费冲突的原话与动作边界、独自求生原话、河边与逃离的两场雨、父母来接又劝回、花呗三万多与剩余八千、手指骨折、郑哥已婚且妻子不出场、G团事故及消费分成、一命服试过但自主停播均保留。不带回早期已删除的感染或醉酒客户支线。

孩子出生当晚，小满心疼、爱护他，逃离时仍有不舍；后来母子因多年分离而不亲。她对吴家的恨不转嫁给新生儿，对孩子的爱也不表示接受被迫生育或放弃自由。没有结婚登记；结尾不扩写其父母。原尾声逐字保留。人物基础见[人物](人物.md)。此前“医学只概述”和“必须收养赴美”的限制已被后续要求替换。

## 生育承诺的实际时间

第7章中内部代号为“回甘肃”的场景发生在生产前：吴小北反复许诺“生完我就让你回甘肃，不拦你”，但仍不先交还手机、证件，小满尚抓着这一期限。不能提前写成她已彻底看穿承诺、不再相信能走。

第4章发生在生产当晚：新生命带来真实喜悦，小满抱孩子、安抚他，随后兑现承诺的请求被吴家母子以孩子需要妈妈等理由推回去。第12章的出逃是此后重新争取自由；后来的心疼、救孩子均不替吴小北取消当年的欺骗。
