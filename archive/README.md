# Git以前的本地归档

`legacy/`保存迁移前的整个小说工作区：

- 各版小说大纲、关键场景试写和旧阅读入口；
- 初稿、第二稿、重写版、prod-001至prod-004；
- 既有版本留存、Notion同步副本、编辑与核验记录。

这些原文件按原路径关系保留在本地，未改正文。原文中的旧绝对路径可能已失效，当前工作请从仓库根目录的README进入。

归档受`.gitignore`保护，不随公开仓库上传；新电脑仅克隆仓库时不会取得它。当前小说和继续修改所需的设定、篇目、脚本与核实资料均已独立纳入Git。

`迁移校验.json`记录本地归档各文件的原始哈希及迁移结果，也不上传。日后的正常修订使用Git历史，不再向归档增加整版副本。
