## 修改与生成

`正文/`中的章文件是小说正文的唯一编辑源。章序和标题由`章节清单.json`管理；`下周照常开团.md`和`章节目录.md`由脚本生成。

只需Python 3标准库：

```sh
python3 工具/合稿.py
python3 工具/合稿.py --check
```

脚本从自身位置定位仓库，换目录或换电脑后仍可运行。生成的链接均为相对路径。`--check`会检查生成文件是否与章文件一致，发现未生成的修改时返回失败。

场景表中的名称与时间仅供编辑，不出现在正文中。调整日记片段时，同时更新`设定/日记场景表.json`和`设定/日记场景与时间.md`，核对非线性顺序下绯月的知情范围。

## Git约定

初始提交保存v4基线，标记为`v4`。后续修订通过Git提交保存；同一轮未合并修改保持一个提交，修正使用amend。具体约定见[AGENTS.md](AGENTS.md)。

创建或更新CR/PR之前先fetch目标分支，需要时rebase；上传前确认比最新目标分支领先一个提交、落后零个提交。保留无关修改和已合并的历史。
